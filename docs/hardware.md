# 硬件连接

## 组成

- 安路 HX1P35A FPGA 开发板及 SC500CS 摄像头。
- EASY-EAI-NANO RV1126B 扩展板。
- HDMI 显示器、业务串口连接线与电源。

## 业务串口

两板采用 3.3 V TTL UART，参数为 1,500,000 baud、8 数据位、无校验、1 停止位。

| RV1126B | FPGA J1 排针 | FPGA 信号 | 器件球号 |
| --- | --- | --- | --- |
| TX | 2 | `uart_rx` | V1 |
| RX | 1 | `uart_tx` | V2 |
| GND | 12 或 30 | GND | — |

发送端连接接收端，两板信号地相连。SoC 板端 UART 寄存器基址为 `0x20810000`。

## 其它接口

| 接口 | 用途 |
| --- | --- |
| 摄像头 MIPI | 输入视频 |
| HDMI | 输出画面与识别状态 |
| 下载接口 | 使用 TD 配套 BitWriter 配置 FPGA |
| `dbg_txd`，N1 / J1 第 23 脚 | 115200 baud 启动信息 |
| `mon_tx` | 115200 baud 运行状态 |
| 蜂鸣器 C12 | 低电平有效的驱离控制输出 |

系统主时钟为 50 MHz，显示时钟为 75 MHz。引脚分配与电气属性以工程约束文件为准。
