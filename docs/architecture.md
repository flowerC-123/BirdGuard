# 系统架构

## 视频与候选检测

摄像头图像经 MIPI 接收、ISP 与 DDR 帧缓存进入视频通路。显示、候选检测和识别取图使用各自的数据支路，识别区域从原始图像提取。

候选检测在 160 × 120 网格上运行。帧差关注相邻画面的变化，背景差分关注目标与背景参考的差异，颜色分割按指定色域筛选，融合模式结合运动与颜色信息。掩膜经邻域支持滤波后形成候选框，系统保存最多四个候选。

显示支持原图、灰度与 Sobel 边缘视图。显示选择在帧边界生效，识别取图继续使用原图支路。

## 区域送检

调度器优先处理有效候选，并穿插网格巡检，为静止目标提供识别入口。区域尺寸按边长与像素预算约束，图像以灰度形式传输。

每笔请求保存会话、请求、帧和区域信息。单请求配置维护一个在途事务，流水配置维护最多四个在途事务。返回结果按身份查找对应记录，再更新目标状态。

## SoC 推理

异步桥接收、校验和组装图像，将完成的请求交给有界队列。推理线程调用 RKNN 程序，提取鸟类检测结果，并构造回传报文。流水配置采用一个推理工作线程，使图像接收与推理在时间上重叠。同步桥在接收一幅图像后调用推理并回传结果，配合单请求 FPGA 使用。

板端业务串口通过内存映射访问 UART 寄存器，采用 1.5 Mbit/s 通信。模型路径由运行配置提供，桥接程序与推理程序使用独立入口。

## 状态与动作

候选位置、识别状态和动作状态分别管理。有效回包同时满足状态、身份、鸟类判定与接口等级条件后，进入驱离控制；动作采用保持与冷却机制。

画面中的 `REF` 为参考电压数值标识。实线候选框表示当前检测区域，`SNAP` 虚线框表示最近一次识别取图区域。
