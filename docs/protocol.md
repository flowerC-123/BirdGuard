# 串口协议

物理层采用 1,500,000 baud、8N1、3.3 V TTL。多字节整数使用小端顺序。

## 报文结构

| 偏移 | 长度 | 内容 |
| ---: | ---: | --- |
| 0 | 2 | 同步字节 `AA 55` |
| 2 | 1 | 协议标识 `01` |
| 3 | 1 | 类型：图像 `01`，结果 `81` |
| 4 | 4 | 会话标识 |
| 8 | 4 | 请求标识 |
| 12 | 2 | 结果体或图像体长度 |
| 14 | 2 | 头部 CRC |
| 16 | 可变 | 报文体 |
| 末尾 | 2 | 整帧 CRC |

校验采用 CRC-16/CCITT-FALSE，初值 `FFFF`，多项式 `1021`。头部校验覆盖偏移 2 至 13；整帧校验覆盖偏移 2 至报文体末尾，包含头部 CRC。

## 图像体

图像体由 20 字节元数据和像素组成。元数据依次为源帧号、区域编号、源图宽高、区域左上坐标、区域宽高、像素格式与保留字节。

当前 FPGA 图像通路发送灰度像素。像素数据不超过 16 KiB，区域宽高分别不超过 256 像素。SoC 解析器将灰度扩展为三通道图像，交给推理程序。

## 结果体

基础结果体包含状态、类别判定、接口等级、标志位和处理时间，共 8 字节。扩展结果体在其后附加四个 16 位字段 `x`、`y`、`width`、`height`，共 16 字节；坐标使用 320 × 240 参考平面。

桥接程序默认以 `BIRD_CONF_MIN=0.30` 作为模型分数门限，将达标分数映射到 80–100 的接口等级。接口等级用于 FPGA 控制判据，模型分数用于 SoC 检测筛选。

FPGA 根据会话和请求身份接收结果。状态为正常、判定为鸟、接口等级达到门限且标志位为零时，更新鸟类确认状态。模拟标志用于测试数据标记。

协议实现位于 [SoC 编解码](../soc/bridge/src/roi_protocol.cpp)，FPGA 收发逻辑位于 [RTL](../fpga/rtl/)。
